# Sonar Prediction Model

A Machine Learning web application that predicts whether an object detected by sonar is a Rock or a Mine.

## Technologies Used
- Python
- Scikit-Learn
- Logistic Regression
- Flask
- HTML/CSS/JavaScript

## Model Performance
- Test Accuracy: 76%

## Features
- Real-time predictions
- User-friendly web interface
- Model deployment using Flask

## Run Locally

pip install -r requirements.txt
python app.py
